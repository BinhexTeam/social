To configure this module, you need to:
---------------

Please note that you must have a developer account previously
set up to perform the configuration described below.
Learn more at [X Developer Portal](https://developer.x.com)

Registering the Client ID and Client Secret.
---------------

- Go to *Social Marketing* > Configuration > Settings
- Activate LinkedIn Account > save
  ![API_KEY_SECRET](/social_media_x/static/img/readme/API_KEY_SECRET.png)

Integration of a user account.
---------------

- Go to *Social Marketing* > Configuration > Social networks
- Click on the *Associate account* button the social network LinkedIn
  ![ASSOCIATE_ACCOUNT](/social_media_x/static/img/readme/ASSOCIATE_ACCOUNT.png)
- Clicking on this will redirect you to X page for authentication,
  and once you validate your details, you will be redirected to the system and
  the Dashboard view where you will see the posts.
  ![AUTHORIZE_ACCOUNT](/social_media_x/static/img/readme/AUTHORIZE_ACCOUNT.png)
- Once you have completed these steps and everything is working correctly,
  you can see your account in *Social Marketing* > Configuration > Accounts
